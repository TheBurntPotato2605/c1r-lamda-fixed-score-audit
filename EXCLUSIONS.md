# Excluded material

An explicit file allowlist was used; nothing else was copied. The following were deliberately **not** published.

| Excluded | Reason |
|---|---|
| Raw LAMDA data (feature vectors, labels, hashes, partitions) | Third-party dataset; the pipeline downloads it from the pinned public revision and verifies size and SHA-256 (nothing is stored here) |
| Per-row sealed score tables, per-row keys/seen table, model checkpoints | Sealed study artifacts; regenerated by the pipeline and hash-checked against pins; only SHA-256 digests (score files, seals, keys table) are published |
| Internal authorization files (`G4_AUTHORIZATION*.json`, `G5_AUTHORIZATION.json`), approval and deviation records, review packages, decision records | Internal approval records; available from the corresponding author on reasonable request |
| Annotation files `RG-N.json`, `RG-S.json`, `RG-T.json` | Contain internal authorization/governance labels; not needed for the published tables, bounds or figures |
| `g3_summary.json` and other G3 run files | Contain row-level provenance entries beyond aggregate counts; only `G3_AGGREGATE_TABLES.csv` is published |
| Private authorization system (`g4_runner.py`, `g4_access.py` gate, ledger/slot/monitor modules) and the original per-slot run directories (manifests, ledgers, model checkpoints) | Governance machinery and sealed artifacts of the original study; not needed to compute anything. The scientific code (G2/G3/G4 adapters, data layer, seal, G5 metrics) **is** published under `pipeline/frozen/`; its relation to the originals is documented in `pipeline/PARITY.md` |
| Independent reviewer's verification scripts and reports of the original study | Authorship/redistribution not established. (The supplementary-metric verifier is published in adapted form from 2.1.0.) |
| Execution-control scripts of the re-executions (resource supervision, scheduling), their logs and the isolated runner copy used for the same-seed check | Operational infrastructure; outcome summaries are in `evidence/` |
| LAMDA code and Springer LNCS class files | Third-party; license not established for redistribution (LAMDA code) / not part of this package |
| Manuscript sources (LaTeX, Word) | Not part of this release |
| Any local machine path, user name or account detail | Privacy; scripts use repository-relative paths |
